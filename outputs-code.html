Code

  1. Epi-R Toolbox: epi-toolbox-r is a collection of helper functions for working with epidemiologic and surveillance data, as well as utilities for loading and managing data files in R and formatting analytical outputs for visualization.
  2. Most Probable Number Enumeration: This code is an implementation of the method described in Cochran 1950. It includes a function to determine the most probable number of bacteria in a given sample based on a specific pattern of positive tubes and replicates. This code was initially published as part of the supplemental material of Weller et al. 2017 and was developed by David Kent and Daniel Weller.
  3. Implementing the FoodNet Trends Bayesian Splines Model: Weller, D., S. Sevilla, E. Rose, J. Forstedt, J. Caravas, and B. Bruce. 2025. Implementing the FoodNet Trends Bayesian splines model.
  4. E. coli Transfer and Survival
  5. Calculating Land Use, Land Cover, and Landscape Structure Parameters: This code calculates the proportion of each land cover class, including cropland, pasture, forest-wetland, shrubland, grassland, barren, open water, developed open space, and developed land, as well as impervious cover around each river, lake, pond, or other sampling site using buffers of 122, 366, and 1098 meters. Buffer distances were selected based on LGMA recommended distances from adjacent land uses likely to present a food safety risk.
  6. lavaan Helper Functions: This repository provides helper functions to label all structural regression coefficients in a lavaan model using Excel-style labels, build the corresponding directed regression graph, and define direct, indirect, and total effects for selected outcomes by enumerating all directed paths.
  7. AVF Replication Analysis: The files in this repository allow replication of the results for “Preharvest food safety and conservation challenges facing US produce growers: Results from a national survey.”
